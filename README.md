📊 Power BI Projects

This repository contains Power BI dashboards created using Excel datasets. These projects focus on business insights such as call center performance, customer churn, retention, and diversity & inclusion.

📌 Projects Overview
🔹 Call Centre Analysis

Analyzes call center performance including:

Call volume

Agent performance

Customer satisfaction

Resolution time

🔹 Churn Analysis

Identifies customer churn patterns and key factors affecting churn.

🔹 Customer Retention

Shows customer retention metrics and long-term engagement trends.

🔹 Diversity & Inclusion

Displays workforce diversity insights such as gender distribution, hiring, and promotions.

🛠 Tools Used

Microsoft Power BI

Microsoft Excel

DAX

Data Modeling
